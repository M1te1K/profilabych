# Профилабыч v0.1.0

Первый публичный релиз модульного Telegram AI-агента для самостоятельного запуска.

## Возможности

- Telegram polling и команды `/start`, `/help`, `/reset`.
- OpenRouter Chat Completions и последовательный Tool Calling.
- Калькулятор, текущее время, сохранение и просмотр заметок.
- SQLite: история по пользователю и чату, заметки по пользователю.
- Московское время по умолчанию (`Europe/Moscow`), явный часовой пояс в запросе.
- Даты хранятся в UTC, даты заметок показываются в локальном формате.
- Жирный текст и inline code через безопасные Telegram entities; разбиение
  длинных ответов с учётом UTF-16 и emoji.
- CLI, офлайн-проверка конфигурации и демонстрация без API-ключей.
- Лимиты инструментов, проверка аргументов, контролируемые повторы HTTP-запросов,
  маскирование ключей и корректное завершение ресурсов.
- README с установкой, BotFather, OpenRouter, `.env`, запуском и тестами.

## Установка

См. [README](../../README.md). Требуется Python 3.12–3.14. Для Telegram создайте
своего бота и ключ OpenRouter. Реальные токены, логи и локальная SQLite не входят
в исходники или архив релиза.

Бесплатность и поддержка инструментов проверяются перед запуском; доступность
модели и квоты зависят от OpenRouter. Платного fallback нет.

## Проверки и ограничения

Результаты проверок кандидата: [отчёт подготовки](../release-preparation.md).
Автоматические тесты выполняются без настоящих Telegram/OpenRouter-запросов.
Онлайн-проверка во время подготовки этого релиза отдельно не проводилась.

Поддерживаются личные текстовые сообщения. Голос, PDF, RAG, группы и облачный
хостинг не включены. Один polling-процесс на токен; многопроцессный запуск
и долговременная дедупликация не реализованы. Компьютер или сервер с ботом
должен оставаться включённым.
