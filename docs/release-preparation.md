# Подготовка Профилабыча v0.1.0

Дата: 10 октября 2026 года. Цель публикации: новый публичный репозиторий
`M1te1K/profilabych`, тег и GitHub release `v0.1.0`.

## 1. Что подготовлено

README переписан для человека, который впервые скачивает проект: клонирование
и выбор тега, Python-окружение, зависимости с хешами, `.env`, BotFather,
OpenRouter, Telegram/CLI, офлайн-демо, тесты, настройки и устранение ошибок.
Добавлены release notes и GitHub Actions для Python 3.12, 3.13 и 3.14.
Проверки GitHub Actions пока не запускались: репозиторий ещё не опубликован.

Версия проекта уже была `0.1.0`. Обновлено описание пакета, существующая
реализация Telegram и московского времени сохранена. README и release notes
явно указывают, что лицензия пока не выбрана. По решению владельца `LICENSE`
не добавлен. Новых рабочих зависимостей нет; lock-файлы сохранены.

## 3. Проверка секретов и данных

- Проверены все файлы кандидата из tracked/untracked, разрешённых `.gitignore`.
- Проверена доступная Git-история всех refs и reflog: один коммит `7ec973d`.
- Выполнены проверка известных форматов ключей и отдельный Gitleaks **8.30.1**.
  Gitleaks проверил исходники и Git-историю; обнаруженных секретов нет.
- Gitleaks загружен из [официального релиза](https://github.com/gitleaks/gitleaks/releases/tag/v8.30.1)
  с проверкой SHA-256 архива. Результаты выводились с полным маскированием.
- Поля `TELEGRAM_BOT_TOKEN` и `OPENROUTER_API_KEY` в `.env.example` пусты.
- `.env`, локальная SQLite и её служебные файлы, логи, окружения и кеши
  не включены в кандидат или исходный архив релиза. Реальный `.env` не читался.
- Проверены правила `.gitignore` для `.env`, БД, логов, ключевых файлов,
  локальных записей и окружения; `.env.example` остаётся доступен Git.
- Проверен состав wheel: только пакет и его метаданные, без ключей и локальной БД.

Сканирование не доказывает отсутствие любого возможного секрета; оно не заменяет
контроль содержимого будущих коммитов. Логи и БД могут содержать личные сообщения
и заметки и остаются локальными.

Чистое окружение: macOS arm64, **Python 3.13.13**. Установка выполнена
по зафиксированным зависимостям из PyPI с `--require-hashes`.

| Проверка | Результат |
| --- | --- |
| Установка `requirements-dev.txt` и editable-пакета в новое окружение | Успешно |
| `python -m pytest` | **292 passed**, 19.89 с |
| `python -m ruff check .` | Все проверки прошли |
| `python -m ruff format --check .` | 52 файла уже отформатированы |
| `python -m mypy src` | Нет ошибок в 30 исходных файлах |
| `python -m pip check` | Нет конфликтов зависимостей |
| `python -m profilabych --check` | Успешно, без сети и БД |

mock session, а OpenRouter — MockTransport.

Отдельно проверены чистая установка рабочих зависимостей `requirements.txt`
и собранного wheel, `pip check`, а также `--check` и `--demo` из каталога вне
исходников. Все завершились успешно.

## 5. Ограничения проверок

- Реальные запросы Telegram/OpenRouter в ходе подготовки релиза не выполнялись.
  Предыдущий отчёт о времени описывает прошлый smoke test; он не является
  проверкой текущей доступности бесплатной модели.
- Python 3.12/3.14, Windows и Linux локально в этой задаче не проверялись.
  Матрица GitHub Actions станет проверяемой после публикации.
- Docker engine недоступен. Попытка открыть установленный OrbStack не удалась:
  приложение не запускается. Сборка и запуск Docker не подтверждены; инструкции
  Docker не представлены как проверенный способ запуска.
- Облачный хостинг, миграции данных и multi-process не входят в релиз.

## 6. Подтверждение и публикация

Владелец подтвердил публичную публикацию 10 октября 2026 года в
`M1te1K/profilabych` без лицензии. Перед публикацией повторно сверены все
62 файла с проверенным кандидатом; изменений исходников после согласования нет.

не обнаружено. Локальные данные исключены из состава публикации.

Согласованный порядок: публичный репозиторий, локальный коммит, отправка `main`,
тег `v0.1.0` на последнем коммите и GitHub Release с подготовленными notes.
Используется обычная отправка без force push. Облачный деплой не выполняется.

Этот документ фиксирует результаты подготовки до отправки финального коммита;
результат публикации и публичные ссылки проверяются отдельно после неё.
